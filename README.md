## 🚀 Projetos de portfólio

### 1. ☁️ [Sales Microservices | Ecossistema de Microsserviços de E-Commerce](https://github.com/Renaneliziario/Sales-Microservices)

**Março de 2026 a setembro de 2026**

**Tecnologias:** Java 17, Spring Boot 3.4.5, Spring Cloud Config, OpenFeign, JPA/Hibernate, PostgreSQL, Docker Compose, Swagger/OpenAPI e Maven.

Sistema de vendas desenvolvido com arquitetura de microsserviços, aplicando separação de responsabilidades, comunicação entre APIs e regras de negócio para gerenciamento de clientes, produtos, vendas e estoque.

**Principais implementações:**

- Ecossistema composto por quatro serviços: Config Server, Cliente, Produto e Vendas.
- Bancos de dados PostgreSQL isolados por serviço.
- Configuração centralizada com Spring Cloud Config.
- Comunicação entre microsserviços utilizando OpenFeign.
- Operações de cadastro, consulta, atualização e exclusão.
- Regras de negócio para processamento de vendas e controle de estoque.
- Tratamento de falhas com compensação manual de operações.
- Orquestração dos serviços utilizando Docker Compose.
- Documentação das APIs com Swagger/OpenAPI.
- Testes automatizados utilizando H2.

**Aprendizados:** comunicação distribuída, consistência de dados, tratamento de falhas e organização de responsabilidades entre serviços.

[🔗 Acessar repositório](https://github.com/Renaneliziario/Sales-Microservices)

### 2. 🦺 [EPI Warehouse | Sistema de Gerenciamento de EPIs](https://github.com/Renaneliziario/epi-warehouse-microservices)

**Tecnologias:** Java 17, Spring Boot, Spring Security, JWT, PostgreSQL, H2, Flyway, Docker Compose, React 19 e TypeScript.

Sistema de gerenciamento de Equipamentos de Proteção Individual inspirado em processos industriais, com backend organizado em microsserviços e interface web para operações de cadastro e controle.

**Principais implementações:**

- Serviços para gerenciamento de funcionários, categorias de EPIs, retiradas e operações.
- Validação de regras de negócio relacionadas a colaboradores e equipamentos.
- Comunicação entre serviços utilizando RestClient.
- Autenticação JWT e proteção de endpoints com Spring Security.
- Persistência de dados utilizando PostgreSQL e H2.
- Migrações de banco de dados com Flyway.
- Docker Compose para execução dos serviços.
- Integração contínua utilizando GitHub Actions.
- Interface web com React e TypeScript para consumo das APIs REST.

**Aprendizados:** modelagem de processos industriais, validação de regras de negócio, segurança de APIs e integração entre frontend e backend.

[🔗 Backend](https://github.com/Renaneliziario/epi-warehouse-microservices) | [🔗 Frontend](https://github.com/Renaneliziario/epi-warehouse-frontend)

### 3. 🏛️ [SalesPersistence-JPA | Persistência com JPA e Hibernate](https://github.com/Renaneliziario/SalesPersistence-JPA)

**Tecnologias:** Java, JPA/Hibernate, PostgreSQL, SQL e Maven.

Projeto de estudo e implementação de persistência de dados para um sistema de vendas, com foco em mapeamento objeto-relacional e organização das operações de acesso ao banco.

**Principais implementações:**

- Implementação de Generic DAO utilizando Java Generics.
- Mapeamento de entidades e relacionamentos com JPA/Hibernate.
- Consultas utilizando Criteria API e JOIN FETCH.
- Separação de responsabilidades em camadas.
- Operações de persistência e manipulação de entidades.

**Aprendizados:** mapeamento objeto-relacional, relacionamentos entre entidades, consultas e abstração de operações de persistência.

[🔗 Acessar repositório](https://github.com/Renaneliziario/SalesPersistence-JPA)

### 4. 🗄️ [SalesSystem-JDBC | Persistência com JDBC e SQL](https://github.com/Renaneliziario/SalesSystem-JDBC)

**Tecnologias:** Java, JDBC, PostgreSQL, SQL e Reflection API.

Projeto voltado ao entendimento do funcionamento da persistência de dados sem depender de frameworks ORM.

**Principais implementações:**

- Conexão direta com PostgreSQL utilizando JDBC.
- Operações CRUD utilizando SQL.
- Consultas parametrizadas com PreparedStatement.
- Gerenciamento manual de transações.
- Implementação experimental de um mini-ORM utilizando Reflection API.
- Separação entre lógica de negócio e acesso aos dados.

**Aprendizados:** SQL, transações, funcionamento do JDBC e conceitos internos utilizados por ferramentas de mapeamento objeto-relacional.

[🔗 Acessar repositório](https://github.com/Renaneliziario/SalesSystem-JDBC)
