## Projetos de portfólio

### 1. [Sales Microservices | Sistema de Vendas com Microsserviços](https://github.com/Renaneliziario/Sales-Microservices)

**Período:** Março de 2026 a setembro de 2026.

**Tecnologias:** Java 17, Spring Boot 3.4.5, Spring Cloud Config, OpenFeign, JPA/Hibernate, PostgreSQL, Docker Compose, Swagger/OpenAPI e Maven.

Ecossistema de vendas desenvolvido com arquitetura de microsserviços, aplicando separação de responsabilidades, comunicação entre APIs e regras de negócio para gerenciamento de clientes, produtos, vendas e estoque.

**Principais implementações:**

- Arquitetura composta por quatro serviços: Config Server, Cliente, Produto e Vendas.
- Persistência com PostgreSQL, utilizando bancos isolados por serviço.
- Centralização das configurações com Spring Cloud Config.
- Comunicação entre serviços utilizando OpenFeign.
- Operações CRUD para gerenciamento de entidades.
- Regras de negócio para processamento de vendas e controle de estoque.
- Tratamento de falhas com compensação manual de operações.
- Orquestração dos serviços utilizando Docker Compose.
- Documentação das APIs com Swagger/OpenAPI.
- Testes automatizados utilizando H2.

**Competências desenvolvidas:** Integração entre sistemas, arquitetura distribuída, consistência de dados, tratamento de falhas e organização de responsabilidades.

**[Acessar repositório](https://github.com/Renaneliziario/Sales-Microservices)**

### 2. [EPI Warehouse | Sistema de Gerenciamento de EPIs](https://github.com/Renaneliziario/epi-warehouse-microservices)

**Tecnologias:** Java 17, Spring Boot, Spring Security, JWT, PostgreSQL, H2, Flyway, Docker Compose, React 19 e TypeScript.

Sistema para gerenciamento de Equipamentos de Proteção Individual, desenvolvido a partir de necessidades observadas em processos industriais.

A solução contempla serviços de backend para gerenciamento de colaboradores, equipamentos e operações, além de uma interface web para consumo das APIs.

**Principais implementações:**

- Serviços para gerenciamento de funcionários, categorias de EPIs, retiradas e operações.
- Implementação de regras de negócio e validações de dados.
- Comunicação entre serviços utilizando RestClient.
- Autenticação JWT e proteção de endpoints com Spring Security.
- Persistência com PostgreSQL e H2.
- Versionamento do banco de dados utilizando Flyway.
- Orquestração dos serviços com Docker Compose.
- Integração contínua utilizando GitHub Actions.
- Interface web desenvolvida com React e TypeScript.

**Competências desenvolvidas:** Modelagem de processos industriais, desenvolvimento de APIs REST, segurança, validação de regras de negócio e integração entre frontend e backend.

**[Repositório Backend](https://github.com/Renaneliziario/epi-warehouse-microservices) | [Repositório Frontend](https://github.com/Renaneliziario/epi-warehouse-frontend)**

### 3. [SalesPersistence-JPA | Persistência com JPA e Hibernate](https://github.com/Renaneliziario/SalesPersistence-JPA)

**Tecnologias:** Java, JPA/Hibernate, PostgreSQL, SQL e Maven.

Projeto voltado ao desenvolvimento de uma camada de persistência para um sistema de vendas, explorando mapeamento objeto-relacional, relacionamentos entre entidades e abstração de operações de acesso aos dados.

**Principais implementações:**

- Implementação de Generic DAO utilizando Java Generics.
- Mapeamento de entidades e relacionamentos com JPA/Hibernate.
- Consultas utilizando Criteria API e JOIN FETCH.
- Separação de responsabilidades em camadas.
- Operações de persistência e manipulação de entidades.

**Competências desenvolvidas:** Mapeamento objeto-relacional, consultas, relacionamentos entre entidades e abstração de operações de persistência.

**[Acessar repositório](https://github.com/Renaneliziario/SalesPersistence-JPA)**

### 4. [SalesSystem-JDBC | Persistência com JDBC e SQL](https://github.com/Renaneliziario/SalesSystem-JDBC)

**Tecnologias:** Java, JDBC, PostgreSQL, SQL e Reflection API.

Projeto desenvolvido para compreender os mecanismos de persistência de dados em Java, utilizando JDBC e consultas SQL diretamente, sem depender de frameworks ORM.

**Principais implementações:**

- Conexão com PostgreSQL utilizando JDBC.
- Implementação de operações CRUD com SQL.
- Consultas parametrizadas utilizando PreparedStatement.
- Gerenciamento manual de transações.
- Desenvolvimento experimental de um mini-ORM utilizando Reflection API.
- Separação entre regras de negócio e acesso aos dados.

**Competências desenvolvidas:** SQL, JDBC, gerenciamento de transações e compreensão dos mecanismos de persistência utilizados por frameworks ORM.

**[Acessar repositório](https://github.com/Renaneliziario/SalesSystem-JDBC)**

Projeto voltado à prática de testes automatizados, com foco na validação de regras de negócio, isolamento de dependências e identificação de falhas em operações de um sistema de vendas.
